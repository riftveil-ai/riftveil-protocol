# Security

## Reporting a security issue

The protocol is a text file: the security issues that concern it are mostly cases where a text submitted to Riftveil manages to override its instructions (prompt injection), or to make it validate, rewrite or conclude. For such a case, or for an issue affecting the online tool at riftveil.ai, write to hello@riftveil.ai rather than opening a public issue. Attach the submitted text, the model and the tool used, and the resulting report. You will receive a reply within seven days.
